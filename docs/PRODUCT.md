# CrunchyRoll Censoring — current product

A local MV3 profanity filter for English captions and matching English-dub audio on Crunchyroll desktop. Version 0.1.9 adds an explicit per-episode CC timing correction for audio and timestamp links, preserving exact-text subtitle association, sync, backups and unlisted store packaging. It remains an integration preview: the live service is inaccessible in this environment. Automatic alignment and universal English-dub coverage are unmet parts of the goal.

## Decisions and acceptance criteria

- Preserve the existing strict TypeScript/esbuild/npm/Playwright release foundation; replace the Page Notes demonstration.
- Use observed playback metadata and only its English subtitle/caption resources. Do not authenticate, request alternate episode versions, change hard-sub streams, or use transcription.
- English audio requires an English CC track belonging to the current playback version. Translated Japanese-version dialogue and signs tracks never drive audio muting.
- Japanese, unknown, and unsupported audio remain unchanged. Manual language selection resolves missing detection only, never missing captions or conflicting reliable metadata.
- Integrate before ASS rendering with recognized SubtitlesOctopus or before browser paint with the identified Bitmovin DOM caption layer. Preserve native styling/timing and original text. Require selected English track metadata and exact cue agreement. Prefer current-time cues; permit one unique full-text cue from that same track without changing audio timing. Unsupported/hardcoded paths report unavailable; never conceal speculative layers.
- Use bounded whole-cue mute padding, media-time scheduling, and per-element mute ownership. Settings and exceptions use a new isolated local schema; old demo data is untouched.
- Provide masked occurrence review, timestamp seeking, per-occurrence Ignore/Unignore, local term settings, retry, and persistent player coverage warnings.
- Keep complete tracks and bounded playback logs only in frame memory; persist only settings and hashed occurrence exceptions. No transcript transmission or general fetch bridge; saved preferences may use user-controlled Chrome Sync.
- Test fixture behavior separately from live service behavior. A release ZIP does not establish live compatibility.
